03

The eight field notes, one line each

  1. Model guessed argument names, strict schema rejected three calls, customer saw the retries. Lenient schemas + aliases + a skill rule.
  2. Paystack fee passed to the customer: checkout ₦8,934.02 for a ₦8,500 order, verify's amount ≠ total. Compare requested_amount.
  3. Paystack rejects .example emails. Configurable payer domain.
  4. Skills API needs migrate before a new skill on a fresh teammate; two responses carry raw control characters.
  5. Railway: GitHub app without repo access, railway up from a subfolder vs root directory.
  6. Demo depended on the clock: headline dish was lunch-only at 16:05. All-day now.
  7. Model used the example reference as real, then confabulated a retraction. References only from this conversation; order number in every link reply.
  8. Reconciler confirmed before the model: the no-webhook design proven.
